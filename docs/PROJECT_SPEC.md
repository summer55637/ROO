# ROO 專案固定規格（必讀）

> 本文件是 ROO 專案方向的持續紀錄。開始新功能、重構、設計或部署前，先讀本文件與根目錄的 `AGENTS.md`。

## 1. 最終目標

製作一款以真正的《仙境傳說 Ragnarok Online》（RO）內容、素材與遊戲規則為基礎的**純單機 H5 RO 遊戲**，不是只模仿 RO 美術或風格的「類 RO」作品。

## 2. 不可偏離的固定條件

- **單機：** 不做多人連線、玩家間互動伺服器或 MMORPG 後端。
- **純前端：** 使用 HTML、CSS、JavaScript 與瀏覽器可執行的技術；不依賴自建後端。
- **免費網址：** 目標是透過 GitHub Pages 提供免費網頁網址，瀏覽器直接遊玩。
- **完全免費、不營利：** 不加入廣告、內購、付費解鎖、訂閱、付費道具或其他營利機制。
- **保留 RO 本體：** 以真正 RO 的職業、技能、怪物、道具、卡片、地圖、素材及遊戲機制為基礎；不能只做外觀相似的替代品。
- **使用既有倉庫：** 優先沿用本倉庫已有的 RO 資料、傷害與屬性公式、職業技能、裝備卡片、存檔與其他系統，避免無故推倒重做。
- **本機存檔：** 以瀏覽器本機儲存（LocalStorage／IndexedDB 等）保存進度，不要求帳號或雲端伺服器。
- **素材授權前提：** 專案作者已明確表示，已取得 RO 遊戲公司完整使用授權，可使用 RO 相關內容與素材。後續規劃依此專案前提進行；若需核對具體限制，依作者持有的授權文件為準。
- **發佈目標：** GitHub Pages 免費網址；尚未確認 Pages 啟用前，不可聲稱正式遊玩網址已上線。

## 3. 現況與目標的區別

目前公開程式的核心仍是放置／自動戰鬥網頁遊戲；這是可沿用的基礎，不代表完整的即時 RO 單機體驗已完成。

後續應逐步補足或改造：
1. RO 地圖探索與角色直接移動。
2. 角色、怪物與必要的逐格動畫／素材呈現。
3. 玩家可操作的即時戰鬥、技能施放與傷害判定。
4. 經驗升級、轉職、裝備、卡片、道具、NPC／任務等 RO 遊戲流程。
5. 純前端存檔、重新整理後續玩，以及手機／桌面瀏覽器操作。
6. GitHub Pages 靜態發布與載入測試。

實作時應先檢查現有程式與資料，盡可能重用已經完成的系統。

## 4. 明確不做的方向

- 不改成有後端或必須連線的多人遊戲。
- 不加入任何營利機制。
- 不把專案目標降成只像 RO 的泛用放置遊戲或只有 RO 風格的仿作。
- 不因為新對話缺少先前聊天紀錄，就忽略本規格。

## 5. 新對話／新工具工作流程

每次新對話要繼續本專案時，先查看：
1. `docs/PROJECT_SPEC.md`（本文件）
2. `AGENTS.md`（倉庫開發規範）
3. `README.md` 與相關程式碼（確認最新實作狀態）

本文件記錄的是**專案目標與作者提供的前提**；實際完成度仍要以倉庫最新程式碼及測試結果判定。


## 2026-10-20 更新：原生探索小地圖第一階段

- 原生／本機地圖探索加入可收合小地圖，依 GAT 尺寸等比例縮放，標示可走地面、水域、懸崖與障礙。
- 角色目前格、尋路線與目的地會同步顯示；地形底圖只在地圖資料變更時重建，避免每幀重算整張地圖。
- 把地形像素與格座標換算抽成獨立模組，加入比例、四種地形色彩與邊界座標測試。
- 此功能為導航輔助，不改動 GAT 碰撞／尋路結果；尚需真實桌面與手機瀏覽器目視驗收。


## 2026-10-20 更新：小地圖點擊移動

- 小地圖支援直接點選目的地，並共用原有 GAT 可行走判定、近鄰吸附與 A* 尋路。
- 3D 地面與小地圖採用同一尋路入口，避免兩種操控方式的障礙處理規則分岔。
- 小地圖畫布獨立套用尺寸規則，確保不受 3D 全畫面 canvas CSS 影響；增加點擊座標反算測試。
- 保持純前端單機，不新增後端、帳號或網路同步。


## 2026-10-20 更新：原生探索怪物佈置第一階段

- 主遊戲把當前地圖的 MAPS／MONSTERS 遇怪資料傳入原生探索。
- 依 GAT 可走格在玩家周圍以外建立最多 8 個穩定怪物位置，排除水域與障礙。
- 優先載入 ragassets 的 RO 怪物 idle APNG；失敗時退回 images/monsters 圖片。
- 點選怪物可查看等級、HP、ATK，小地圖同步標示；無怪物清單的城鎮不生怪。
- 此階段完成佈置與目標選取；攻擊、傷害、經驗與掉落仍待接回引擎。


## 2026-10-20 更新：原生探索普攻接回主遊戲引擎第一階段

- 探索頁新增「靠近並自動普攻」：按 GAT 可走格尋路至怪物相鄰格，再按玩家攻速自動出手。
- 同源分頁透過 localStorage 事件傳送短指令；主遊戲分頁驗證目前地圖與怪物資料，再呼叫既有 playerAttack()／monsterAttackSingle()。
- 普攻沿用原引擎的命中、暴擊、屬性、防禦、職業被動、怪物反擊、擊殺、經驗、職業經驗、金幣、道具與卡片流程；沒有另造一套簡化傷害公式。
- 避免探索目標與放置戰鬥陣列互相污染：引擎暫時借用目標陣列結算後復原；擊敗獎勵仍寫入現有角色 state／存檔。
- 必須同時開著相同來源的主遊戲分頁；後續已接入主動攻擊技能第一階段（見下節）。怪物刷新、3D 攻擊特效與完整戰鬥 UI 尚未完成，實際桌面／手機瀏覽器仍待目視驗收。


## 2026-10-20 更新：原生探索主動攻擊技能第一階段

- 主遊戲開啟原生探索時，會傳入角色已學的直接攻擊技能清單；探索頁選中怪物後可選技能與等級。
- 目標距離超過一個 GAT 格時，先依既有 A*／通行格走至怪物相鄰格，再施放所選技能。
- 探索頁透過同源 localStorage 指令呼叫主遊戲分頁的 `castRoExplorerSkill()`；引擎會重新驗證地圖、怪物與已學技能，再呼叫既有 `castSkill()`，沿用 SP／冷卻／傷害、命中與技能資源規則，不另造傷害公式。
- 技能結算暫時借用單一探索目標怪物陣列，完成後還原放置戰鬥陣列。回歸測試涵蓋合法技能、未學技能拒絕、冷卻、SP 消耗、傷害與放置怪物資料隔離。
- 本階段只支援直接攻擊技能；施毒與中毒／出血持續計時已在下節接入。其他持續傷害／異常技能、主動輔助技能、完整 3D 技能特效與怪物刷新尚未接完。仍需同源主遊戲分頁保持開啟，並完成桌面／手機真實瀏覽器畫面驗收。


## 2026-10-20 更新：原生探索中毒／出血持續狀態第一階段

- 探索技能清單加入「施毒」；施放時仍走主引擎 `castSkill()` 的命中、SP、冷卻與傷害流程。
- 探索頁只追蹤已套用中毒／出血計時的目標，透過同源指令呼叫 `tickRoExplorerMonsterStatus()`；引擎暫時借用單一目標陣列，使用既有 `tickPoisonDot()`／`tickBleed()`，再還原放置戰鬥資料。
- 狀態跳傷、怪物死亡、回報 HP、計時節流與放置怪物陣列隔離均有回歸測試。
- 計時器會在頁面離開時停止，從 BFCache 返回時恢復；已完成語法、探索戰鬥專項、完整回歸、全遊戲 Smoke Test 與主要資料語法檢查。
- 仍待真實桌面／手機瀏覽器視覺驗收；其他持續傷害技能、完整異常狀態／技能場域、主動輔助技能和 3D 技能特效尚未全部接完。


## 2026-10-20 更新：原生探索怪物重生第一階段

- 野外怪物被主引擎普攻、主動技能或中毒／出血持續傷害擊敗後，等待 8 秒再重生。
- 重生優先選原出生點附近的 GAT 可走格，排除水域、玩家近身格及其他存活怪物占用的位置；附近無合法格時每秒重試。
- 重生會恢復該目標最後回報的最大 HP、清除探索 UI 的狀態標籤，並換用新的 spawnKey，避免重用主引擎已標記死亡的戰鬥紀錄。
- 主引擎探索目標紀錄增加 30 分鐘過期清理及 2,048 筆上限，防止持續重生長時間累積舊目標。
- 新增重生週期專項測試：等待時間、唯一目標識別、HP／狀態重置、重生位置與玩家／其他怪物／水域避讓。
- 限制：此階段仍是探索預覽的簡化生怪生命週期；不代表正式 RO 各地圖重生時間／出生區域已逐一還原，也尚未完成桌面與手機的真實瀏覽器視覺驗收。


## 2026-10-20 更新：回歸測試抽樣穩定性

- 修正服事／祭司「沉默之術」機率測試：原本使用真正隨機的 200 次抽樣，偶爾會在 20%±8% 範圍外造成 CI 偶發失敗。
- 測試改用可重現且覆蓋 100 個百分位的均勻序列，200 次應精確觸發 40 次；被測試的正式遊戲機率邏輯沒有更動。


## 2026-10-20 更新：探索施毒技能入口接線

- 主遊戲「開啟 3D 探索」產生已學技能清單時，加入 poison_proc 類型，確保「施毒」會從主遊戲送到探索頁。
- 新增跨檔測試，核對主遊戲技能清單、探索頁允許類型與引擎實際允許類型一致；避免單一層已實作技能、入口卻沒有傳入的情況。


## 2026-10-20 更新：原生探索戰鬥目標 UI 隔離

- 目標切換後，舊目標的普攻／技能回覆、中毒／出血跳傷及死亡通知不再覆蓋目前選取目標的資訊面板和狀態訊息。
- 每個目標仍各自更新 HP、狀態、死亡／重生資料；只有目前選取的目標能改動右上角目標面板與戰鬥狀態文字。
- 新增靜態 UI 接線測試，因現有 Node 測試治具不會載入瀏覽器專用 tools/ro_explorer.mjs 實際 DOM。


## 2026-10-20 更新：離線打寶模式比較測試可重現

- 瘋狂模式的離線擊殺數比較使用依地圖識別碼產生的固定抽樣序列，普通與瘋狂模式成對比較，降低短時間戰鬥樣本中命中／暴擊波動造成的 CI 偶發失敗。
- 仍保留擊殺數倍率與淨經驗倍率兩個斷言；只放寬短樣本擊殺比的下界，避免把合理抽樣波動誤判為倍率未生效。


## 2026-10-20 更新：原生探索 HP／SP 狀態列
- 開啟原生探索時，主遊戲會傳入角色目前 HP、最大 HP、SP 與最大 SP。
- 探索頁持續顯示角色 HP／SP 比例；主引擎普攻、技能與持續狀態回覆會同步更新數值。
- 選取怪物後顯示 HP 血條，沿用主引擎回報的實際 HP，不另造傷害或資源公式。
- 新增狀態條格式／邊界回歸測試；真實桌面及手機瀏覽器外觀仍需目視驗收。


## 2026-10-20 更新：原生探索 HP／SP 即時同步
- 探索頁每秒透過同源 `localStorage` 指令向主遊戲分頁讀取當前 HP、最大 HP、SP、最大 SP，顯示自動戰鬥、自然恢復與補品造成的數值變動。
- 輪詢回覆使用獨立 requestId，逾時可重試；切離頁面會停止輪詢並清除待回覆識別，返回 BFCache 後恢復。
- 不新增後端、帳號或傷害公式；同源主遊戲分頁仍須保持開啟。
- 新增跨檔接線回歸測試，涵蓋快照來源、輪詢、requestId 過濾及頁面生命週期。

## 2026-10-20 更新：原生探索背景分頁生命值輪詢
- 探索頁切到背景時停止每秒 HP／SP 同源輪詢，避免隱藏分頁持續交換不需要顯示的快照。
- 回到前景或從 BFCache 返回時立即恢復同步；切換到非原生模式則持續停止輪詢。
- 請求端另行檢查頁面可見度與生命週期，避免停止輪詢後仍送出新的快照命令。
- 新增跨檔回歸檢查，覆蓋背景暫停、前景恢復與頁面離開保護。

## 2026-10-20 更新：原生探索戰鬥傷害跳字
- 原生探索普攻、已接通主動攻擊技能及中毒／出血持續傷害會在目標上方顯示短暫跳字。
- 正常傷害按攻擊類型使用不同顏色，零傷害顯示 MISS；拒絕、節流或沒有有效傷害數值的回覆不會誤顯示。
- 跳字層只覆蓋 3D 場景且不攔截點擊；使用相機投影定位，依動畫時長自動回收，離開頁面時清理。
- 新增格式與跨檔接線測試，納入完整回歸及 CI 語法檢查。

## 2026-10-20 更新：原生探索玩家受傷回饋
- HP／SP 同源快照或已驗證的普攻、技能回覆確認玩家 HP 下降時，在角色位置顯示紅色負數跳字。
- 使用前後兩次引擎回報 HP 的差值，不新增怪物傷害公式；無法確認舊 HP、HP 未下降或回覆過期時不顯示。
- 將生命值更新與 requestId 驗證順序整理，避免無效的狀態計時回覆觸發受傷提示。
- 新增受傷文字格式與跨檔回歸檢查；納入既有戰鬥回饋測試。



## 2026-10-20 更新：原生探索視角本機保存

- 依地圖 ID 把相機位置與觀察目標保存在瀏覽器本機，重新載入同張地圖時恢復視角。
- 以地圖尺寸正規化座標，調整世界比例後仍能還原相近視野；按「重置視角」會把預設視角重新保存。
- 拒絕格式版本錯誤、非有限值、超出安全範圍或不合理距離的視角資料；無法讀取時回退預設視角。
- 不新增伺服器、帳號或網路同步；無法使用 localStorage 時探索照常運作。


## 2026-10-20 更新：原生探索停止移動／接近

- 移動路徑存在時，工具列顯示「停止移動／接近」按鈕；抵達或沒有有效路徑時隱藏。
- 停止時依角色當前世界位置回算 GAT 格，只接受可走格，再對齊角色、保存本機位置並清除路徑線。
- 同時取消自動攻擊接近與尚未施放的排隊技能，避免停止後被戰鬥邏輯重新拉回移動。
- 加入跨檔接線測試並納入完整回歸；不變更 GAT 碰撞、A* 尋路或傷害公式。


## 2026-10-20 更新：原生探索角色跟隨視角

- 原生探索預設啟用相機跟隨：角色移動時，相機位置與觀察目標同步平移，讓角色保持在視野內。
- 工具列可取消「跟隨角色視角」自由查看地圖；重新勾選會把視角聚焦到角色並保存在本機。
- 載入地圖時，若啟用跟隨，先依本機保存的角色格聚焦視角；行走期間沿用實際角色位移，不改動移動速度、GAT 碰撞或尋路。
- 新增相機位移純函式與跨檔接線測試，納入完整回歸及 CI 語法檢查。
- 尚需真實桌面／手機瀏覽器目視驗收。


## 2026-10-20 更新：原生探索異常狀態回報

- 原生探索戰鬥回覆同步顯示主引擎已掛上的昏迷、冰凍、石化、睡眠、混亂、黑暗、詛咒、中毒、出血與沉默狀態。
- 狀態名稱與有效期限讀取既有 `MON_AILMENTS`／`ailActive()`，不重寫命中、抗性、持續時間或傷害公式。
- 狀態過期後，探索頁的狀態輪詢會更新清單並停止排程；中毒／出血仍由主引擎既有 tick 函式結算傷害。
- 增加引擎測試，覆蓋多狀態同步、重複中毒去重及過期清除；納入完整回歸。


## 2026-10-20 更新：原生探索基礎／職業進度 HUD

- 原生探索的角色狀態面板新增基礎等級、基礎經驗進度、職業等級、職業經驗進度與鋅幣顯示。
- 初次開啟時由主遊戲帶入快照；後續沿用既有 HP／SP 同源輪詢，約每秒更新一次，打怪獎勵與升級因此能反映在探索畫面。
