# 諸神放置錄 — RO 單機 H5 遊戲專案

目前倉庫中的可玩版本以放置／自動戰鬥為核心；專案固定目標是發展成**真正的《仙境傳說 Ragnarok Online》（RO）純單機 H5 遊戲**，不是只仿 RO 風格的類 RO 作品。
使用 HTML / CSS / JavaScript，無須自建後端，目標透過 GitHub Pages 免費網址直接遊玩，存檔保存在玩家自己的瀏覽器。

## 怎麼玩

1. 開啟 `index.html`，選一個存檔欄位建立角色（分配六圍屬性點）。
2. 戰鬥場景可用 **WASD／方向鍵、畫面方向鍵或點擊空地**移動角色；位置會跟著角色存檔保存。
   目前先完成場景操作，地形碰撞、逐格尋路與手動即時戰鬥仍是後續工作。
3. 進遊戲後會自動戰鬥，經驗值、鋅幣、掉落物全自動累積。**關掉分頁也會繼續打**
   （離線掛機上限 24 小時）。
3. 「⚔️ 自動戰鬥」分頁設定要放哪些技能、什麼時候補血補魔。
4. 等級到了「🔔 可以轉職了！」會亮起，到「🌳 轉職樹」分頁轉職。

**轉職路線**：新手 → 一轉 → 二轉 →（轉生）→ 進階二轉 → 三轉

| 階段 | 門檻 |
|---|---|
| 一轉 | 基礎 10 ／職業滿級 |
| 二轉 | 基礎 40 ／職業滿級 |
| 轉生 | 基礎 99 ／職業滿級 ／ 200 萬鋅幣（每隻角色限一次） |
| 進階二轉 | 基礎 70 ／職業 50 |
| 三轉 | **基礎 99 ／職業 70** → 解開等級上限 200、素質上限 130 |

## 主要系統

**戰鬥**
- RO Renewal 風格的傷害鏈：體型／屬性／種族修正**只作用在武器 ATK**上，
  素質 ATK 與熟練度加成不吃這些懲罰
- 硬防走比例減傷 `(4000+DEF)/(4000+10·DEF)`、軟防每擊固定扣血，兩者分開計算
- 命中／迴避／完全迴避／暴擊各自獨立判定；暴擊無視閃避與防禦
- 官方 ASPD 公式：攻擊間隔 = 20 × (200 − ASPD)，上限 190（未滿 100 級）／193
- 屬性相剋、種族與體型修正、異常狀態（中毒／沉默／黑暗／昏迷／冰凍…）

**放置**
- 離線結算（上限 24 小時）、自動補血補魔、自動購買藥水
- 近戰模式一次最多 5 隻怪（隨機生 1~3 隻）、遠攻模式固定 1 隻
- BOSS 模式：可切換成只遇頭目

**打寶模式**（三轉後開放）
- 一般／瘋狂兩檔：怪物 HP ×3／×5、攻擊 ×2／×3、經驗與掉落 ×5／×10
- 開啟時整個介面會染紅，一眼看得出來
- **遺物系統**：打寶模式專屬的第二套裝備，六套 × 8 件，2/3/5 三段門檻，
  8 個獨立欄位可混搭（例如 5 件法師 + 3 件刺客）

**其他**
- 隊友系統（雇傭、自動戰鬥設定、承傷分配、自動復活）
- 卡片插卡、裝備精煉、鍛造、倉庫、圖鑑、成就
- 素質洗點（10 萬鋅幣，退點照當初實際花掉的階梯成本算）

## 給想改的人

**資料驅動**：遊戲內容集中在 `js/data.js`（怪物／地圖／道具）、`js/skills.js`、
`js/jobs.js`、`js/relics.js`。引擎不寫死任何職業或怪物名稱，加內容基本上只要加資料。

**載入順序**（`index.html`）：
```
about.js → hp_sp_tables.js → img_alias.js → aspd_data.js → skills.js
→ monster_skills.js → jobs.js → data.js → relics.js → achievements.js
→ engine.js → ui.js
```

**測試**：`node tools/test.js` 跑 40 個測試檔。治具會把整個遊戲載進 Node 真的跑起來
（不是靜態分析），但**不載入 `js/ui.js`**——畫面的部分要開瀏覽器看。
改完 JS 記得 `node --check`，語法錯誤測試抓不到。

**GM 測試面板**：正式版預設關閉，網址加 `?gm=1` 才會出現（例：`index.html?gm=1`）。
